The Jupyter notebook script "Merging Data and Calculating RSA Metrics.ipynb" can be used to replicate the results starting from the minute physiological and posture values. The notebook has headings explaining each new important step that is taken. Thus, one can also start using the script starting at a place/section of interest. Simply identify the excel file you need and download that data file from this repository, and continue from there.

None of the excel sheets have the data of the three participants who did not give permission for their data to be used in other research studies. If you would like to replicate to the exact statistics, reach out to the corresponding author for the full data set.

df_ema_merged.xlsx is deleted as it contains sensitive information (including the emotional/affective state of participants). If you would like to replicate the findings for Research Question 3 (i.e., prediction of safety and other psychological states), reach out to the corresponding author.
